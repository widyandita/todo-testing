# TodoMVC Automation Testing

This repository showcases a simple **QA Automation Testing** project for the TodoMVC React application using **Playwright**. The project demonstrates fundamental automation testing concepts, including functional testing, assertions, and failure reporting.

## Test Coverage

The automated test suite covers the following scenarios:

1. **Application Load Verification**

   * Verify that the TodoMVC application loads successfully.
   * Validate that the page title matches the expected value.

2. **Todo CRUD Operations**

   * Create multiple todo items.
   * Mark a todo item as completed.
   * Edit an existing todo item.
   * Delete a todo item.
   * Clear completed items.
   * Verify the application state after each operation using assertions.

3. **Failure Demonstration**

   * Execute an intentionally failing test to demonstrate Playwright's debugging capabilities.
   * Capture failure artifacts such as screenshots, videos, traces, and HTML reports.
